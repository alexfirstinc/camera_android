# NIGHTFALL // Protocol

A polished, original first-person shooter vertical slice built with Three.js. Infiltrate an arctic relay compound, engage autonomous sentries, and explore a fully procedural environment.

## Run

```bash
npm install
npm run dev
```

Click **Deploy mission**, then use WASD to move, mouse to aim, click to fire, Shift to sprint, and R to reload.

## Quality features

- ACES filmic tone mapping, soft shadows, atmospheric fog, and dynamic tactical lighting
- Procedural brutalist environment, mountain skyline, road, snow, and relay tower
- Responsive FPS controller, recoil, weapon sway, hit markers, ammo, reloads, and destructible targets
- Cinematic mission briefing and a responsive tactical HUD
- Mobile-aware layout with a touch fire control
