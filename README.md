# Gua Compass (Android + Web)

Проект содержит два варианта приложения:

1. `android-app/` — Android-приложение (целевой API 36, Android 16) на Kotlin.
2. `web/` — HTML + JavaScript версия.

## Возможности

- Выбор пола из выпадающего списка.
- Выбор даты рождения через выпадающие списки (день/месяц/год).
- Кнопка расчета числа Гуа.
- Цветной восьмиугольник с числами Гуа.
- При вращении телефона восьмиугольник поворачивается, а числа остаются ориентированными на стороны света (на основе компаса/датчиков; для Android также учитывается GPS и магнитное склонение).

## Запуск Android

Открыть папку `android-app` в Android Studio и выполнить запуск на устройстве с датчиками ориентации.

## Запуск Web

Открыть `web/index.html` в мобильном браузере (лучше по HTTPS), предоставить доступ к датчикам и геолокации.
